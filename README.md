# hydrogenase-feature-extractor

Extracts quantitative features from hydrogenase protein structures for
comparative analysis and downstream computational workflows.

## Scope
- Compute structural and geometric descriptors
- Derive cofactor- and active-site-related features
- Support tunnel, cavity, and environment-based measurements

## Output
- Structured feature tables (e.g. CSV, JSON)
- Feature vectors suitable for statistics or machine learning

## Intended use
Structure analysis, dataset generation, and model development involving
hydrogenase enzymes.
